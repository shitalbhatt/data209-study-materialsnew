# YouTube upload pack

Channel: https://youtube.com/@data209eda

`videos.csv` has the order, playlist, file, title (max 100 characters), description and tags for each of the 21 videos.

## Playlists to create (YouTube Studio > Content > Playlists > New playlist)
1. DATA209 Module 1: Statistical and Data Foundations
2. DATA209 Module 2: Core Advanced EDA
3. DATA209 Module 3: Data Quality and Anomaly Management
4. DATA209 Module 4: Feature Engineering, Transformation and Structure

## Upload steps
1. Studio > Create > Upload videos. Select the files from `site/slide-videos/` (download the repo first).
2. Paste the title and description from `videos.csv`. Add the tags under "Show more".
3. Audience: "No, it's not made for kids". Add to the module playlist.
4. Visibility: Unlisted first (check the playback), then Public if the university allows.
5. Channel settings > Basic info: add the channel description below.

Channel description:
> Lectures and labs for DATA209 Advanced Exploratory Data Analysis (B.Tech Hons. Data Science, Vidyashilp University). Slides, code walkthroughs and revision material. Study site: https://shitalbhatt.github.io/data209-study-materialsnew/
