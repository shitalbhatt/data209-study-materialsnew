# Module 1: Statistical and data foundations (L1-6)

## EDA vs confirmatory
| | Exploratory | Confirmatory |
|---|---|---|
| Question | What is going on? | Is this claim supported? |
| Hypothesis | Generated by analysis | Fixed before seeing data |
| Output | Hypotheses, clean data | p-values, CIs |

Never test a hypothesis on the rows that suggested it: split first, explore one part, confirm once on the held-out part.

Five jobs of EDA: sanity, quality, structure, hypotheses, modelling decisions.

## Sampling and bias
Population -> frame -> sample -> estimate. Bias is systematic and does not shrink with n; variance shrinks about 1/sqrt(n). Error = Bias^2 + Variance + irreducible noise.

## Shape
- Right skew: mode < median < mean. Left skew: mean < median < mode.
- Excess kurtosis = kurtosis - 3 (tails, not peak).
- IQR fence: Q1 - 1.5 IQR to Q3 + 1.5 IQR.
- Symmetric: report mean + SD. Skewed: median + IQR.

## Data types
Nominal (mode) < Ordinal (+median) < Interval (+mean, no ratios) < Ratio (everything).
Discrete = counted, continuous = measured. Structured vs semi-structured. Time series = trend + seasonality.

## Images, audio, dimensionality, ethics
Everything is numbers (1024x1024x3 = 3,145,728). Curse of dimensionality: 10^d points needed. Ethics: Consent, Privacy, Fairness, Consequence; split every summary by group.
